# 🍴 Restaurant Management System (RMS)
A professional .NET Core MVC application designed for modern restaurant operations.

## 🚀 Key Features
* **Role-Based Access Control (RBAC):** Distinct dashboards for Admins, Chefs, and Waiters.
* **Order Workflow:** Real-time status updates (Pending -> Confirmed -> Preparing -> Ready -> Completed).
* **Staff Notifications:** Automatic toast alerts for the kitchen and floor staff.
* **Table Management:** Automatic status switching (Available/Occupied).
* **Business Intelligence:** Sales reports with Pie Charts and Top-Selling item analysis.
* **Performance:** Server-side pagination using LINQ for high-speed data handling.

## 🛠️ Tech Stack
* **Backend:** ASP.NET Core 8/9, Entity Framework Core
* **Database:** Microsoft SQL Server
* **Frontend:** Bootstrap 5, Bootstrap Icons, JavaScript (Toasts)
* **Architecture:** Repository Pattern & Service Layer
